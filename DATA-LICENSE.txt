THIS REPOSITORY HAS TWO LICENSES. READ THIS PART.
================================================================================

GitHub's sidebar reports a single license for a repository, detected from the
LICENSE file. It therefore shows "MIT" here. That label is correct for the CODE
and WRONG for everything else. The actual split:

CC BY 4.0 -- data and written work (this file):

    PAPER_2026-08-20.md          the paper
    *.md at the repository root  protocol, results, audits, reconciliation,
                                 reviews, handoff, data notice and index
    *.html at the root           the two published summary pages
    results/**                   24 run-record directories: record.json,
                                 meta.json, score.json, cli_result.json and the
                                 de-identified transcripts
    holdout/*.json               calibration, fuzz, mutation and scoring results
    holdout/*.md                 scoresheets and manual-acceptance documents
    fixtures/**                  the five task prompts
    archive/**                   the retained voided run

MIT -- code (see LICENSE):

    tools/**                     measurement, analysis, index control and the
                                 de-identification gate
    holdout/**.py                oracle, scorer, differential fuzzer, mutation
                                 harness
    holdout/refimpl/             reference implementations

A NOTE ON WHAT THE DATA CONTAINS
================================================================================

results/**/transcript.jsonl holds verbatim agent session records, including
model output produced by Anthropic's Claude models during the runs. They are
published as the study's evidence. Read DATA_NOTICE.md before reusing them: it
records, item by item, what was removed from these files before publication and
proves that no measured value changed.
