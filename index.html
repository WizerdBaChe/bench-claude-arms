這份研究不宣稱什麼

成本結論成立的前提是品質被固定住。以下五條限定在任何摘要裡都不得被壓縮掉， 完整版在倉庫的 CLAUDE.md 規則 1–5：

  1. 「等品質」只在契約層成立 —— 有一次執行拿滿分，卻交出載不進資料夾的 GUI。
  2. GUI 篩檢的 2/3 對 0/3 是 Fisher p=0.4，描述性，不得與 n=4 的成本結論並排。
  3. GUI 那項發現量到的是組內離散度，不是「委派讓 GUI 變差」。
  4. 推理強度的 thinking −33% 不是節省：總成本只降 5%，統計上無法區分。
